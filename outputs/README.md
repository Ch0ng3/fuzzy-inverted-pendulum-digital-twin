# outputs/ — generated results (can be regenerated)

| Folder | Content | Produced by |
|---|---|---|
| `figures/` | Scenario plots, control surfaces, membership functions, Simulink screenshots, animation frames | `main_compare.m`, `export_model_figures.m`, `main_twin(.., true)` |
| `results/` | `comparison.csv` / `comparison.mat` (metrics of the four scenarios), the four `.fis` files | `main_compare.m` |
| `videos/` | `twin_mamdani.mp4`, `twin_sugeno.mp4` and their GIF previews | `main_twin(1, true)`, `main_twin(2, true)` |

Everything here can be deleted and regenerated by running the main scripts.
